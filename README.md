# NEON VEIL

Киберпанк-детектив / immersive sim от первого лица. Vesper City, 2091 год: воспоминания записывают, редактируют и продают.
Вы — Ной Каррен, бывший следователь отдела мнемо-преступлений. Женщина в красном плаще просит найти её брата,
инженера корпорации HYPERION. Очень скоро выясняется, что в этом деле нельзя верить ни свидетелям, ни уликам, ни собственной памяти.

Браузерная 3D-игра: **Three.js + TypeScript + Vite**. Вся графика, текстуры, модели и звук генерируются процедурно — в репозитории нет ни одного бинарного ассета.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # режим разработки → http://localhost:5173
```

Готовая сборка лежит в `dist/` (её нужно отдавать через любой статический сервер, не через `file://`):

```bash
npm start          # пересобрать и открыть (vite build && vite preview)
# или без пересборки:
npx vite preview   # → http://localhost:4173
```

Рекомендуется Chrome / Edge / Firefox с аппаратным ускорением, наушники и полноэкранный режим (F11).
Если тормозит — «Настройки → Отражения: выкл / Качество: низкое».

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift | движение, бег |
| Мышь | обзор (клик по экрану — захват курсора) |
| E | взаимодействие: осмотр, разговор, двери, терминалы |
| Tab | журнал расследования (задачи, улики, досье, хроника) |
| I | инвентарь, использование предметов и шардов памяти |
| B | доска расследования |
| M | карта города |
| Q | всплыть из воспоминания |
| 1–9, Пробел | выбор реплики, продолжить диалог |
| F5 / Esc | быстрое сохранение / пауза |

Между районами перемещаются через станции транзита (метро / монорельс).

## Что реализовано

- **4 района** с собственной атмосферой и интерьерами: Центральный (проспект, офис детектива, лапшичная, пост полиции, крыша с пиратским передатчиком),
  Нижний ярус (рынок, бар, клиника с задней комнатой), Жилой сектор (двор, вестибюль, этаж 7, квартира Элиаса), комплекс HYPERION (плаза, вестибюль, Лаб-7, дирекция).
- **Окружение**: дождь, мокрый асфальт с настоящими отражениями и кругами от капель, туман, неон и bloom, динамический свет, пар, движущийся транспорт
  (тормозит перед игроком), летающие машины, прохожие, дроны, процедурный эмбиент и музыка.
- **Расследование**: 35 фактов (люди, места, события, улики), осмотр предметов, документы, скрытые улики, запись камеры наблюдения с перемоткой и отметкой кадров.
- **Доска расследования**: игрок сам соединяет карточки и выбирает тип связи. Осмысленные связи рождают версии — в том числе ложные.
  Рабочая гипотеза открывает реплики и действия; игра не сообщает, верна ли она. Ошибочные гипотезы ведут к аресту невиновной, рейду, жучку на воротнике.
- **MEMORY DIVE**: три погружения в отдельные 3D-сцены со своей визуальной обработкой. Игрок изучает детали и сам выносит вердикт «подлинное / подделка»
  (одно воспоминание подделано, одно — нет, хотя выглядит подозрительно); в третьем нужно восстановить порядок событий.
- **10 сюжетных NPC** с биографией, секретами, уровнем доверия и памятью о ваших поступках; тональности реплик — дружелюбие, давление, манипуляция, подкуп, обман, угроза —
  работают по-разному на разных людей. Плюс фоновые персонажи с репликами.
- **Альтернативные решения**: в HYPERION можно попасть подкупом, обманом по старому жетону, шантажом или взломом служебного шлюза; запись соседки — получить по доверию,
  купить или украсть; доверие хирурга — заработать лекарством, поручительством бармена и т. д.
- **Взлом терминалов** — мини-игра на дедукцию кода с таймером, три уровня защиты, одноразовый дешифратор.
- **Побочные задания** и экономика (кредиты, взятки, покупки на чёрном рынке).
- **7 концовок**, вытекающих из действий в мире (куда вы отнесли архив, кого сдали, кому сказали правду), с эпилогом, собранным из ваших решений.
- **Интерфейс**: главное меню, настройки, HUD, диалоги, журнал, инвентарь, доска, карта, экран сохранений (3 слота + авто + быстрое), экран финала. Масштабируется от 1280×720 до 4K.

## Архитектура

```
src/
  main.ts              загрузка шрифтов, старт
  engine/
    gfx.ts             процедурные текстуры, материалы, неоновые вывески, фасады, модели людей
    env.ts             мокрая земля (Reflector + свой шейдер), дождь (GPU), небо, силуэт города, пар
    post.ts            пост-обработка: bloom, хроматика, зерно, виньетка, режим «воспоминание», глитч
    audio.ts           процедурный звук на WebAudio: дождь, гул, музыка, шаги, эффекты
  world/
    level.ts           конструктор уровней: коллайдеры, комнаты, двери, NPC, интерактив
    central.ts         Центральный район + общие системы (транспорт, прохожие, витрины, метро)
    zones.ts           Нижний ярус, Жилой сектор, HYPERION
    memories.ts        три сцены MEMORY DIVE
  game/
    game.ts            ядро: цикл, игрок и коллизии, состояние, диалоговый движок, доска, сейвы
    data.ts            персонажи, предметы, факты, связи и версии, задания
    dialogues.ts       диалоговые деревья
    story.ts           сюжетные триггеры в мире и сборка концовок
  ui/
    ui.ts              весь интерфейс (DOM поверх canvas)
    minigames.ts       взлом и просмотр камер
  style.css
```

Сюжет полностью описан данными (`data.ts`, `dialogues.ts`, `story.ts`) и общается с движком через небольшой API (`flag/set`, `clue`, `give`, `trust`, `hack`, `ending`…).

## Известные ограничения

- Персонажи и окружение собраны из процедурных примитивов: это стилизованный low-poly, а не фотореализм; лицевой анимации и озвучки нет (вместо голоса — «печатающийся» текст).
- Нет прыжков и вертикального перемещения: этажи соединены лифтами с затемнением.
- Районы — отдельные уровни, переход между ними через транзит, а не бесшовный.
- Прохожие декоративны и не имеют коллизий; у транспорта простая логика.
- При первом входе в район возможна короткая пауза на компиляцию шейдеров.
- Сохранения хранятся в `localStorage` браузера; сохраняться во время погружения в память нельзя.
- Геймпад и мобильные устройства не поддерживаются. Язык игры — русский.
- Проверка проводилась автоматическим прохождением в headless-Chromium с программным рендером; на реальной видеокарте производительность не замерялась.
